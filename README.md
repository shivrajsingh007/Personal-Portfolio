# Personal-Portfolio
💼 Personal Portfolio Website

A modern and responsive personal portfolio website built using HTML and CSS only.
This project showcases my profile, skills, projects, and achievements in a clean and professional layout.

The goal of this project is to create a simple yet visually appealing portfolio that represents my work as a developer and helps others explore my projects easily.

🚀 Features

🧑‍💻 Personal introduction section

📂 Projects showcase

🏆 Top performer / achievements section

📱 Fully responsive design

🎨 Modern UI with clean styling

🔗 Navigation between sections

🖼 Profile image section

🛠 Technologies Used

HTML5

CSS3

Google Fonts
